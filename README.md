# Personal Portfolio

This repository contains a modern portfolio website for Dhiraj Prabhakar Patil.

## Files included
- `index.html` – main portfolio page
- `assets/css/style.css` – site styling
- `assets/js/script.js` – interactive navigation and sidebar behavior
- `assets/images/` – local SVG assets used by the site

## Publish on GitHub Pages
1. Push this repository to GitHub.
2. Open the repository in GitHub.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main` / `master`
   - Folder: `/root`
5. Save.
6. GitHub will provide a live URL like:
   `https://<your-username>.github.io/<repository-name>/`
